AIX BOT Privacy Policy

Last updated: November 6, 2026

AIX BOT is a Discord server onboarding bot. This policy explains what information it stores when members use its onboarding features.

Information stored

AIX BOT may store a member's Discord user ID and server ID, selected language (English or Sorani), optional gender selection, selected games, and whether the member accepted the server rules. This information is stored in the bot operator's local SQLite database.

How information is used

The information is used to remember onboarding choices, show a member their onboarding profile, and complete the server's verification flow. The bot does not need Discord message content to provide these features.

Sharing and retention

The bot operator does not sell this onboarding information. Information remains in the bot's database until the operator deletes it or removes the database. The server owner or bot operator may be able to access the database.

Security

The bot operator should keep the database and bot credentials secure. Do not share bot tokens or publish the database publicly.

Contact

For questions or a request to delete onboarding information, contact the Discord server owner or the AIX BOT operator through the server.
